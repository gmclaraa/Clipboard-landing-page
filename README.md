# Clipboard Landing Page

Landing page desenvolvida como um desafio do [Frontend Mentor](https://www.frontendmentor.io/challenges/clipboard-landing-page-5cc9bccd6c4c91111378ecb9).

O projeto foi desenvolvido para praticar a criação de layouts responsivos e a construção de uma página seguindo um design pré-estabelecido.
